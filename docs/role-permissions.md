# 角色权限

| 角色 | 首页 | 可视化大屏 | 资源总览表/资源管理项 | 历史报告 | AI巡检解读 | 巡检/运维变更/AI会话/系统管理 |
|---|---|---|---|---|---|---|
| 系统管理员 admin | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 大屏查看员 dashboard_viewer | ✓ | 只读 | — | — | — | — |
| 资产管理员 asset_manager | ✓ | ✓ | ✓ | — | — | — |
| 报告查看员 viewer | ✓ | — | — | 只读、下载 | ✓ | — |

所有角色可进入个人资料页、修改自己的密码和退出登录。

在“系统管理项 → 用户管理”创建或编辑用户时选择角色即可。权限调整在下一次请求时生效，无需用户重新登录。

旧 operator（系统操作员）账号在权限判断时兼容为资产管理员；不会自动获得巡检、AI会话或其他管理权限。系统管理员可以编辑旧账号，明确选择新的角色。

报告查看员的 AI 权限限于巡检解读及其必要接口（巡检记录选择、启用模型列表、本人解读流读取与停止），不能修改模型、创建 AI 会话、调用远程命令或处理审批。资产管理员可以新增、编辑、删除、导出服务器与服务资产，以及通过原有二次密码验证查看凭据；不能发起巡检或操作运维变更。

后端采用与菜单共享的权限策略，未列出的功能默认拒绝有限角色。隐藏菜单不能替代接口权限检查。
