# 安全专项复测（2026-11-05）

## 已确认并修复：权限撤销不及时

风险：高。登录会话 Cookie 保存角色；原实现只校验会话中的用户名和角色，数据库账号降权或删除不能立即撤销旧会话的权限。

修复：在请求安全入口读取当前账号；账号不存在则清除会话，API 返回 401；账号存在则使用数据库当前角色覆盖会话角色。

回归：AccountRevocationSecurityTests 验证管理员降为查看员后不能访问用户管理、用户列表不再返回数据；操作员删除后旧会话访问资产接口返回 401。两项通过。
